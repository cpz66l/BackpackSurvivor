# 轻量夜战氛围

当前地图的蓝灰工业色调保留，以冷月光、工业照明和低密度风尘建立夜间作战感。中心战斗区域仍有环境补光，敌人、宝箱的稀有度颜色和地面标记保持可读。

## 接口与重建

Unity 编辑器调用 `BackpackSurvivor.EditorTools.NightAtmosphereBuilder.ApplyToActiveScene()`；菜单为 `Tools / Backpack Survivor / Art / Apply Lightweight Night Atmosphere`。只处理当前场景，不打开或保存场景；调用方在总体构建完成后保存。重复调用只重建自有的 `NightAtmosphere_Local_176ParticleCap` 根节点，不叠加粒子发射器。

运行组件为 `BS.Presentation.EnvironmentEffects.NightAtmosphere`，跟随当前场景玩家的水平位置。保留固定地面高度，因此不会受旧版玩家根节点在地下的偏移影响。粒子使用世界空间模拟，已经发出的风尘不会跟随角色移动。

## 美术参数

- 主光沿用原方向，强度从 1.25 调为 0.82，冷蓝白色；软阴影仍由原主光承担。
- 三色环境补光分别为天光 `(0.38, 0.46, 0.58)`、水平补光 `(0.25, 0.31, 0.40)`、地面补光 `(0.14, 0.18, 0.24)`。
- 仅增强已有工业 Spot：暖色 5.6、冷色 5.1，仍无阴影，不创建实时光源。
- 线性远雾从相机距离 28 米开始，到 108 米结束，采用暗蓝色。正常战斗地面受影响较轻，远端工业场逐渐融入夜色。
- 风尘为主，少量细雨为辅。没有大雾片、爆闪、发光雪点、屏幕空间叠加或后处理依赖。

## 资源预算

| 项目 | 默认值 / 上限 |
|---|---:|
| 粒子系统 | 2 |
| 风尘最大存活粒子 | 120 |
| 细雨最大存活粒子 | 56 |
| 总存活粒子硬上限 | 176 |
| 默认发射量 | 10 + 6 = 16 个/秒 |
| 调参允许的总发射上限 | 18 个/秒 |
| 粒子贴图 | 1 张 64×64 RGBA32，无 Mipmap，约 16 KiB 像素数据 |
| 材质 / Shader | 1 个共享透明 Unlit 材质 / 1 次纹理采样 |
| 额外粒子几何上限 | 352 个三角形 |
| 新增实时灯 / 粒子阴影 / 碰撞 / 噪声 / 拖尾 | 全部 0 |

贴图由编辑器生成，路径为 `Assets/BackpackSurvivor/Art/Effects/Night/NightAir_Radial64.png`。材质使用 `NightAir_Shared.mat`；Runtime 只引用共享资产，不实例化纹理或材质。组件停用时清空粒子，无需要手工回收的运行时材质。

透明 Shader 有相机近距离淡出（8–16 米）和地面高度淡出（0–0.75 米），不读取深度纹理。小尺寸、低透明度粒子减少前景遮挡；深度测试保留，落到地面以下自然不可见。

升级三选一或暂停时使用游戏的缩放时间冻结粒子，与角色和敌人的暂停行为一致。HUD 为 Overlay Canvas，天气不会盖住升级卡片。编辑器 Inspector 可调风速、覆盖范围、数量与透明度，数量和发射速率有硬限幅。

## 集成验收

整体集成已生成 `unity-content-audit.json`：Night Air Shader 支持当前平台，编译错误和警告均为 0；地图仍只有原有 1 盏主光与 4 盏工业 Spot；两套天气系统的硬上限分别为 120 和 56，默认发射量为 10 和 6 个/秒。`upgrade-runtime-check.json` 已通过实际经验升级与按钮选择确认，选择期间粒子冻结，选择完成后恢复游戏时间。

实际画面、完整验证链接和资源统计见同目录 README。本文预算是组件配置与 Unity 资源估算，不代表整场景 GPU 帧率实测。
