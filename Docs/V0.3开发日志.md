## v0.3.0.1 · 版本管理切换与内容基线准备

### 目标

- 将 V0.3 开发从“第几课”切换为“版本号 / 模块号”管理。
- 建立 V0.3 开发日志入口。
- 明确 AI 协作规则：核心架构用户亲写，重复样板可由 AI 加速。
- 暂不改代码，等待 V0.3 内容池进一步确认。

### 改动

- 新增 `Docs/V0.3版本管理.md`。
- 新增 `Docs/V0.3开发日志.md`。
- 已将 `Docs/V0.3开发计划.md` 与 `plan.md` 中的 V0.3 课时制表述改为版本模块表述。

### 验收

- V0.3 后续开发可以按 `0.3.x` 和 `0.3.x.y` 推进。
- 版本管理规则包含：版本号规则、文档规则、AI 协作规则、提交规则、能力展示目标。
- 本次只做文档切换，不修改 Unity 工程代码。

### Bug / 风险

- 风险：V0.3 内容扩展过快，可能导致升级、邻接、武器、音频、Boss、存档互相抢边界。
- 对策：每个模块只开一个主目标，小快照版本必须可验收后再推进。
