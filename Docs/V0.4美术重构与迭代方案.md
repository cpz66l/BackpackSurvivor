# V0.4 美术重构与迭代方案

日期：2026-09-08。状态：开发中；本轮交付是 v0.4 的美术与展示模块，不表示 v0.4 已发布。已发布的 Windows Demo 仍为 v0.3。

## 目标与现状

延续已认可的夜战回收场与简化三选一界面，让 HUD、背包、掉落提示、暂停和结算呈现同一套蓝灰工业风格，并控制贴图、透明覆盖与运行开销。先用生图形成统一视觉稿，再提取少量真正需要的美术贴图；文字、网格、进度条、按钮与布局使用原生 UGUI。

当前项目使用 Unity 6000.3.20f1 / URP，已有完整 15 分钟单局、纯 C# 背包、升级候选池、对象池、本地记录与设置。工作区包含之前已实现但尚未提交的美术内容，不能以 Git HEAD 覆盖这些工作。

## 视觉规则

- 基础色采用深蓝灰与暖白，少量琥珀/薄荷色提示状态；面板细边、小圆角、清楚留白。
- 不增加重型装甲边框、霓虹光圈、铆钉阵列、六边形纹样、无意义符号或大面积发光。
- 背包外层使用克制的布料/硬质包边意象，中心开口严格匹配真实网格；装饰不参与射线或放置判断。
- 装备光柱沿用当前装备/背包稀有度色：白、绿、蓝、紫、红，避免玩家现有颜色记忆失效。已确认的宝箱配色继续沿用其原始束表色，不擅自修改数据。
- 稀有度同时保留文字/图标线索，低血量保持数字可读，不用单一颜色承载全部信息。
- 所有窗口沿用项目字体和同一组按钮/面板比例，默认不替玩家选中选项。

## 具体布局

HUD：左上生命/等级/经验；上中倒计时与波次；右上金币和最近补给信息；下方短操作提示。战斗中心保持通透。面板之间避免与玩家、交互提示和伤害数字争抢注意力。

背包：仍以420×560为放置与面板外丢弃边界；格子65×65加5间距，物品与格子共享明确的左上原点。外框、标题与价值条属于装饰层，不能放到每次重绘会清空的ItemLayer。保留原物品图标，不将升级插画误用为不同类型的背包物品。

暂停：一张中等宽度的简洁卡片，三个有明确文字的按钮。仅Paused状态显示，升级与结算时不叠开。继续复用原恢复状态函数；重开与回菜单复用场景加载，不增加新存档行为。

结算：横向布局，标题与结果状态、两行统计、两个主要按钮。直接展示已有RunResult，胜负/得分/带出计算不做改写。

场景：保持120m、出生采样、碰撞、原道具布局和敌群路线。只在现有视觉层调整地面标线对比、补给辨识度、灯光明暗及可证实的资源配置；不增加实时灯数量，不把地面做得更花。

## 代码改动边界

优先修改场景、Prefab变体、材质、Sprite与Editor构建器，新增少量Presentation组件。现有控制器通过SerializedObject重新绑定新视觉对象，不重写规则。

当前允许的必要代码点：GameSession仅开放原PauseRun/ResumeRun给暂停/继续按钮；DropItem仅增加可空视觉初始化钩子；ResultView/MainMenuController仅增加场景目标配置与必要的既有统计显示；InventoryUIController仅补暂停/结算时不切换隐藏背包的状态判断。若遇到其他阻断美术交互的问题，只做可说明的小修补并写入变更清单。库存数据、合并/邻接、伤害、波次、概率、经验门槛、存档与对象池算法保留。

实施前保存当前ArtFull场景副本，并记录GamePlay、Inventory、Core全部C#文件SHA256；实施后逐项比对，明确列出允许的小改动，避免混入玩法改造。

## 轻量预算与验证

- 继续复用现有1024²升级插画图集和中文字体。新增UI贴图以512²为优先，确有需要才用1024²；关闭UI Mipmap和Read/Write，Standalone压缩，目标新增纹理载荷不超过2 MiB（不含已存在共享字体）。
- 光柱采用共享网格/材质的少量三角形和解析渐变，不新增Light、碰撞体、阴影、屏幕模糊或后处理。距离淡出/飞行与回池隐藏，实际资源开销在验收时记录。
- 保留夜间天气既有176粒子上限与5盏场景灯。没有实测前不承诺FPS提升。
- 视觉检查至少1600×900与1024×768；检查升级、暂停、背包、结算之间不叠加抢输入。
- 回归：HUD数值、6×8坐标、拖拽/旋转/合并/邻接、真实掉落与池复用、Esc继续、重开、返回主菜单、胜负结算、重复点击保护，以及Shader/编译/原生控制台。
- 本轮状态、视觉稿、实机截图、资源预算与验证记录统一放在 `Docs/ArtDirection/V0.4/`。

## 执行顺序

1. 完成当前状态检查、保护快照与本方案。
2. 生成统一四屏视觉稿与必要的背包包边资产，检查克制度和一致性。
3. 并行制作HUD/主菜单、背包、暂停/结算、掉落光柱；串行接入同一Unity场景。
4. 进行真实运行与资源检查，修复具体问题，保存交付说明与截图。
